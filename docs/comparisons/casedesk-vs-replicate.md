# CaseDesk vs Replicate

Replicate runs models on Replicate-managed infrastructure and charges for that
runtime. CaseDesk is a private AI control plane: it routes to infrastructure
your organisation or selected provider controls.

| Question | CaseDesk | Replicate |
|---|---|---|
| Where does runtime execute? | Your approved connection | Replicate infrastructure |
| Who receives the runtime bill? | Your cloud or provider | Replicate |
| What does the platform charge? | Prepaid CaseDesk service fee | Hosted model usage |
| Regional control | Your selected environment and declared boundary | Provider options |
| Trial | Customer-funded connected endpoint after free API sandbox | Provider product terms |

Choose CaseDesk when you need one compatible API and governed routing without
transferring runtime ownership to a platform provider.
