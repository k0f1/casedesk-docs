# Connect an On-Prem Runtime

CaseDesk supports a connected trial only when it can verify an existing
OpenAI-compatible endpoint, its region, and its data boundary. The current
self-service flow does not install an agent or model into your on-premises
environment.

## Recommended path

1. Run the approved runtime under your organisation's operational controls.
2. Provide a securely reachable HTTPS endpoint or request a reviewed private
   connectivity design.
3. Submit the endpoint through **Settings** with its region, data boundary, and
   model contract.
4. Activate the trial only after CaseDesk verifies the connection and your
   organisation's payer declaration.

This preserves your network and runtime ownership. CaseDesk does not use an
on-prem connection as a reason to provision fallback cloud capacity.
